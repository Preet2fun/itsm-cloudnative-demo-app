# Lens 5 — Theme ↔ Roadmap Review

**Purpose:** check planned work against live customer signal — and surface asks
with no roadmap coverage.

**Question:** For each roadmap item, does the customer signal support the plan?

**Inputs:** the roadmap items (pasted, or a landscape scan with no input); the
data source; `../../knowledge-hub/` for what already ships.

**Do:**
1. For each item, find the matching feedback theme and its volume + trend.
2. Recommend one of:

   | Label | Meaning |
   |---|---|
   | **Accelerate** | Strong, rising signal — consider pulling forward |
   | **Maintain** | Signal supports the current timeline |
   | **Defer** | Weak or declining signal |
   | **Merge** | Several items address one underlying need |
   | **Stop** | No signal, or signal contradicts the premise |
   | **NEW** | A strong theme with **no** roadmap item — unaddressed |

3. Rank the **NEW** flags by volume + trend.

**Produce:** the item-by-item table (recommendation + evidence) · the ranked
NEW list · 1–2 attributed quotes per non-obvious call (Accelerate / Stop / NEW) ·
Limitations.

**Feeds:** `ai-product-strategy/` (roadmap sequencing); each **NEW** flag is a
raw idea for `ai-discovery/` stage 01, arriving with its signal already sized.
