# Company & Product Brief

## Identity

- **Company:** Ockham
- **Product:** Ockham

Named for **William of Ockham**, the 14th-century philosopher behind **Occam's
Razor**: when multiple explanations fit the same evidence, prefer the one with
the fewest assumptions.

That principle **is** root cause analysis. During an incident, many stories fit
the symptoms — bad deploy, noisy neighbour, network blip, attack. The job is to
find the simplest explanation the evidence actually supports and discard the rest.

## What we're building now

Full-fledged **observability** with an **agentic AI layer** on top for
autonomous operation.

## Security direction

Long-term vision is a **CNAPP** scoped to **cloud-native assets only**. Near-term
security focus:

- **CDR** — Cloud Detection and Response
- **VM** — Vulnerability Management for cloud VMs and container assets
- **CSPM** — Cloud Security Posture Management
- **eBPF-based runtime signals** feeding dynamic prioritization of vulnerabilities
  and CSPM findings — replace theoretical risk with observed evidence
  (see [`ebpf-signal-thesis.md`](ebpf-signal-thesis.md))
- Then **agentic AI security use cases** on top

## Far-future vision

Complete **AI observability & security for the AI stack** itself.
