# Stage 01 — Idea Intake

**Purpose:** turn a raw idea or signal into a stated problem, and do a fast fit
check before spending any research effort.

**Inputs:** the raw idea / signal + provenance; `../context-hub/` (positioning,
ICP); `../knowledge-hub/` (does this already exist?).

**Do:**
1. **Restate as a problem.** If the idea is a feature ("add X"), write the
   problem it implies and validate that — not the feature.
2. **Type it:** pain signal · feature request · competitive gap · strategic bet ·
   new tech capability. The type shapes which research matters in stage 03.
3. **Provenance:** where it came from, who's asking, how loud the signal is.
4. **Already covered?** Check `knowledge-hub/` — shipped, partly shipped, or
   previously killed? If previously killed, what has changed since.
5. **Fast fit check:** one line each on ICP fit and positioning fit. If it
   obviously fails both, say so now — a 10-minute Kill beats a 3-day one.

**Produce — `01-idea-intake.md`:** Problem restatement · Type · Provenance ·
Existing-coverage note · Fast fit check.

**Gate:** the problem (not the feature) is stated. If it clearly fails fit, jump
to stage 06 with a Kill.
