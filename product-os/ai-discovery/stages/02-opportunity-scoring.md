# Stage 02 — Opportunity Scoring

**Purpose:** size the opportunity and decide whether there's a real AI-native
angle — a structured lean, before deep research.

**Inputs:** `01-idea-intake.md`;
[`../opportunity-scorecard.md`](../opportunity-scorecard.md); `../context-hub/`
(competitors, agentic use cases, eBPF thesis, ICP).

**Do:**
1. Score the **five factors** (magnitude, frequency, severity, competition,
   contrast) 1–5, each with a one-line reason and its **AI angle**.
2. Run the **AI-native check** — Native or Bolt-on, with the reason. Bolt-on is a
   Kill / Park signal.
3. Run the **Ockham-fit gates** — ICP, positioning, moat, horizon.
4. Write the **lean:** Pursue / Park / Kill, and the single biggest reason.

**Produce — `02-opportunity-scoring.md`:** the filled scorecard + lean + reason.

**Gate:** every factor scored with its AI angle; the AI-native check answered;
the lean stated. A Bolt-on verdict or a failed fit gate carries straight to
stage 06.
