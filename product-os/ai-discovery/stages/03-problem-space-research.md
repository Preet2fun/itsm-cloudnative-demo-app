# Stage 03 — Problem-Space Research

**Purpose:** replace opinion about the problem with synthesized evidence — only
as much as the lean needs.

**Inputs:** `01`–`02`; [`../research-methods.md`](../research-methods.md); the
signals the user connects (interviews, tickets, usage, churn, sales notes).

**Do:**
1. **Signal synthesis** — one row per signal (what · source · date · said vs
   did); cluster into themes; name the gap.
2. **JTBD** — one primary, plus secondaries.
3. **Current-state journey** — the steps today, the friction / time / cost at
   each, where users drop or work around.
4. **Affected personas** — from `../context-hub/icp.md`; who feels it most.
5. **Evidence-gap list** — verified vs assumed. "Not found" is recorded, not
   hidden.

**Produce — `03-problem-space-research.md`:** Signal table + themes · JTBD ·
Journey map · Personas · Evidence-gap list.

**Gate:** the primary JTBD is stated and the evidence-gap list is explicit. If
there's no evidence the problem is real, carry a Kill to stage 06.
