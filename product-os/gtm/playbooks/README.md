# Playbooks

Step-by-step for one situation. The first four are **Ockham's named sales
plays** — each maps to a behavioural trigger in
[`../../context-hub/icp.md`](../../context-hub/icp.md) and a Tier-1 signal in
[`../signal-library.md`](../signal-library.md). The last two are general motions
from the GTM starter kit.

| Playbook | Trigger |
|---|---|
| [renewal-price-shock](renewal-price-shock.md) | An observability renewal window or a public price-increase reaction |
| [compliance-deadline](compliance-deadline.md) | A datable SOC 2 / DORA / audit / questionnaire deadline |
| [ops-vs-attack](ops-vs-attack.md) | A public incident where "attack or outage?" took hours |
| [cloud-migration](cloud-migration.md) | A Kubernetes / cloud-migration milestone |
| [new-signal-response](new-signal-response.md) | Any Tier-1 / Tier-2 signal fires — validate → score → act |
| [competitor-switch](competitor-switch.md) | A fixed-7 competitor is in the stack, mentioned, or up for renewal |

Each: **Trigger · Situation · The play · What to say · What not to do.**
