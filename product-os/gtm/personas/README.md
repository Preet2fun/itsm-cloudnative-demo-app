# Personas

One file per buyer role in an Ockham deal. Derived from
`../../context-hub/positioning.md` § "Core pitches by buyer" and
`../../context-hub/icp.md`. Used by the plays to pick the right stakeholder,
channel, and hook.

| Persona | Decision role | File |
|---|---|---|
| IT Director / Head of Infrastructure / CIO | Economic buyer (and champion in smaller orgs) | [`it-director-cio.md`](it-director-cio.md) |
| VP Engineering / Head of SRE / IT Ops lead | Technical buyer / evaluator | [`vp-engineering-sre.md`](vp-engineering-sre.md) |
| Security lead (first security hire, or security-minded platform eng) | Influencer / evaluator — present only in some deals | [`security-lead.md`](security-lead.md) |

Each file: Overview · What they care about · How they buy · How to reach them ·
Message framework · Sample outreach hook.

Messaging matrix across all three: [`../messaging-by-persona.md`](../messaging-by-persona.md).
