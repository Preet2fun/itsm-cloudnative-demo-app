# Outputs

Every research brief, scoring run, and campaign produced by a play lands here.
Six months of outputs next to the context that produced them is the feedback
loop — you can see which campaigns worked, how the ICP shifted, and where the
signal library was right or wrong.

## Naming

```
outputs/YYYY-MM-DD-research-<account>.md
outputs/YYYY-MM-DD-scoring-<name>.md
outputs/campaigns/YYYY-MM-DD-<campaign-name>/
    brief.md · sequences/ · metrics.md · results.md
outputs/weekly-log.md        ← one line per weekly-update run
```

## Never commit here

CRM records, contact lists, verified emails, raw call/meeting transcripts, API
keys, or commercial terms. Outputs hold *analysis and copy*, not customer data.
Summarise and synthesise transcripts into the relevant `context/` file instead.
