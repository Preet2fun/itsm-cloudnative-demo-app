# Launch Plan

How Ockham goes to market, phased against readiness. Gated by
[`../ai-launch-strategy.md`](../ai-launch-strategy.md) — **do not advance a phase
while a gating cell (Customer Pain, AI Reliability, GTM Viability) is Red.**

Last updated: 2026-09-04 · Current phase: **Design partner (pre-launch).**

---

## Phases

### Phase 0 — Design partner *(now)*

- **Goal:** 2–3 design partners through the same IT-Director motion; one
  reference logo; first measured time-to-first-hypothesis POC pass.
- **Audience:** Tier 1 only ([`icp-tiers.md`](icp-tiers.md)) — perfect fit + a
  live Tier-1 signal.
- **Motion:** founder-led. Hand-written outreach
  ([`playbooks/new-signal-response.md`](playbooks/new-signal-response.md)),
  direct POC offer, pricing latitude for a reference + co-build feedback.
- **Exit criteria:** AI Reliability and GTM Viability off Red on the canvas.

### Phase 1 — Limited availability

- **Goal:** repeatable motion — known buyer, cycle length, price point; 3+ deals
  closed the same way.
- **Audience:** Tier 1 + Tier 2, signal-triggered.
- **Motion:** founder + first AE/SDR; `plays/signal-to-sequence.md` campaigns;
  the four playbooks operational.
- **Exit criteria:** GTM Viability Green; Customer Pain off Red (named-customer
  VoC via `../ai-feedback/`).

### Phase 2 — GA

- **Goal:** scale outbound + inbound; expansion motion (Observe → Secure).
- **Audience:** full Tier 1–3.
- **Motion:** full plays + workflows + `sync/` automation; paid channels only
  once the canvas is mostly Green.

---

## Channels (priority order)

1. **Founder-led outbound** to Tier 1 — the only channel in Phase 0.
2. **Thought leadership** on the convergence thesis (the unified-budget / one-team
   argument; the eBPF one-sensor idea; "you can check its work"). Owned content,
   not paid.
3. **Community** — SRE / platform / cloud-security spaces; `../ai-feedback/`
   `signal-scan` surfaces where the ICP is already talking.
4. **Events** — regional CIO / IT-leader roundtables.
5. **Paid** — deferred until the canvas is mostly Green (Brand Power is Red today).
